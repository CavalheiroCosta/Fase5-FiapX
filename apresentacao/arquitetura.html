Arquitetura do sistema

O que sobe no Compose

O front fala com a Auth e com a Video API. O binário fica no MinIO. As filas carregam referência e resultado. Dois processors consomem a mesma fila. A Video API é a dona do registro.

A seta tracejada é a Video API consumindo a fila status. O processor não escreve no Postgres. O Redis guarda marca:{id} enquanto o trabalho dura e lista:{login} para a listagem. Prometheus raspa GET /metrics sem token. O Grafana lê o Prometheus.

Serviços

Serviço Descrição Onde olhar
Front Tela em que a pessoa entra, cadastra usuários, envia o vídeo, acompanha o andamento e baixa o ZIP. localhost:5173
Auth API Reconhece quem pode usar o sistema e emite o token de acesso. Não processa vídeo. localhost:5298
Video API Recebe o vídeo, acompanha o status, lista os envios daquele login, entrega o ZIP e avisa o dono quando o processamento falha. localhost:5299
Processor Lê o vídeo, extrai um frame por segundo, gera o ZIP e devolve o resultado. Não atende o usuário. localhost:5300 e localhost:5301
Postgres usuários Guarda o cadastro de quem usa o sistema: login, nome, e-mail e a senha protegida. localhost:5432, banco fiapx_usuarios, usuário fiapx, senha fiapx
Postgres vídeos Guarda o registro de cada vídeo: dono, status e a referência dos arquivos. O binário não fica aqui. localhost:5433, banco fiapx_videos, usuário fiapx, senha fiapx
MinIO Serviço responsável por manter os arquivos dos vídeos enviados e o ZIP gerado após o processamento. API localhost:9000, console localhost:9001, usuário fiapx, senha fiapxfiapx
RabbitMQ Leva o pedido de processamento e o resultado de volta. A mensagem traz a referência, não o arquivo. painel localhost:15672, usuário fiapx, senha fiapx
Redis Guarda a listagem que o usuário vê e a marca que impede o mesmo vídeo em dois processors ao mesmo tempo. localhost:6379, senha fiapx
Mailpit Recebe o e-mail de aviso quando um vídeo falha. No ambiente local a mensagem não sai da máquina. painel localhost:8025
Prometheus Coleta as métricas das APIs, dos bancos, da fila, do storage e do Redis. localhost:9090/targets
Grafana Mostra, num painel só, o que o Prometheus coletou. localhost:3000, usuário fiapx, senha fiapx, dashboard FIAP X

Um vídeo, do envio ao ZIP

  1. O front pede login à Auth. A senha certa devolve um token de 30 minutos. Sem token válido não há envio, lista nem download.

  2. A Video API grava o arquivo no MinIO, registra o vídeo como aguardando no Postgres e só então publica o identificador e o caminho na fila.

  3. Se a fila falha, o vídeo continua pendente. Se o storage falha, não nasce registro. Se o registro falha depois do arquivo, a API apaga o objeto.

  4. Um processor marca o vídeo no Redis. Se a marca já existe, confirma a mensagem e não processa de novo.

  5. Avisa que começou, extrai um frame por segundo e grava o ZIP. Sucesso só sai com o ZIP já salvo. Erro confirma a mensagem e não volta para a fila.

  6. A Video API grava em processamento, concluído ou erro. Vídeo já fechado não reabre. A listagem sai do Redis. No concluído, o download entrega o ZIP. No erro, o e-mail sai depois do status gravado.
