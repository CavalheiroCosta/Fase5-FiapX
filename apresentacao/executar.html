Como executar o projeto

Subir, entrar e mostrar

Na pasta do Compose, um comando sobe os dois Postgres, o Redis, o RabbitMQ, o MinIO, o Mailpit, o Prometheus, o Grafana, as três APIs, os dois processors e o front. O schema nasce com a Auth e com a Video API.

Subir

Docker em execução. O comando roda em Fase5-FiapX, onde está o compose.yaml. A primeira vez constrói as imagens.

docker compose up -d --build

Depois que as imagens já existem, docker compose up -d basta. Para acompanhar: docker compose ps.

Abrir este guia

start .\apresentacao\index.html

Onde entrar

Tela Endereço Acesso
Front http://localhost:5173 Adm / Adm abre o cadastro e os atalhos do Grafana, do Prometheus, do MinIO, do RabbitMQ e do Mailpit. Outro login abre os vídeos.
Grafana http://localhost:3000 fiapx / fiapx. Dashboard FIAP X. O botão do front já abre /d/fiapx.
Prometheus http://localhost:9090/targets Sem senha. Confira os alvos em UP, inclusive os dois processor.
MinIO http://localhost:9001 fiapx / fiapxfiapx. Bucket videos.
RabbitMQ http://localhost:15672 fiapx / fiapx. Fila processamento com dois consumidores.
Mailpit http://localhost:8025 Sem senha. Depois do Compose, a caixa já tem o assunto FIAP X: o vídeo não foi processado.

Na câmera

  1. Com tudo de pé, abra http://localhost:5173.
  2. Entre como Adm / Adm. Cadastre um usuário, por exemplo login ana, com um e-mail ana@fiapx.local. Abra os atalhos do ambiente. No Prometheus, os alvos estão UP. No Mailpit, a caixa já tem um aviso de erro.
  3. Saia e entre com esse usuário. Envie dois vídeos curtos. A lista mostra o status daquele login: aguardando, em processamento, concluído.
  4. No concluído, baixe o ZIP. No MinIO, o objeto é {id}/{id}.zip. No RabbitMQ, a fila processamento tem dois consumidores.
  5. Para o erro, envie um arquivo com extensão de vídeo que o ffmpeg não lê, por exemplo um texto renomeado para .mp4. A lista fica em erro, o ZIP não aparece e o Mailpit mostra a mensagem para o e-mail do dono.
  6. No Grafana, aponte os painéis de fila, processor, status aplicado, listagem, download e e-mail de erro.
  7. No GitHub Actions do repositório, abra o workflow: build, SonarCloud e as imagens. O endereço é https://github.com/CavalheiroCosta/Fase5-FiapX.

Amostra de vídeo

Não versionar o arquivo. Dois mp4 curtos bastam para a lista. Um vídeo mais longo deixa a chave marca:{id} visível enquanto o ffmpeg roda.

ffmpeg -f lavfi -i testsrc=duration=2:size=160x120:rate=1 -pix_fmt yuv420p amostra.mp4

Fora do Compose

Com a Auth em localhost:5298 e a Video em localhost:5299, o front também sobe assim, dentro de src/Web:

npm install
npm run dev
